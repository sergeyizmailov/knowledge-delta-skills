# Playbooks — vertical shapes, not strategies

Each file answers one question: **what is different about this vertical on TikTok that the generic
protocol would not surface?**

None of them contains a recommended structure, budget, or targeting set. Those come from the intake
and derivation in `references/01-research-protocol.md`, against the account in front of you. A
playbook that told you "casino: 3 ad groups at $50, Purchase event, men 25–54" would be wrong for
most accounts and stale within a quarter.

What a playbook does give you:

- the **gate** — what has to be true before this vertical can run at all, and its lead time;
- the **payout-event shape** — what typically pays, and the optimization-event ladder that follows;
- the **failure modes** specific to this vertical on TikTok;
- the **numbers you must get from the operator**, because they cannot be inferred.

Use one as the checklist for steps A and B of the protocol. Then derive.

| File | Covers |
|---|---|
| `ecommerce.md` | DTC, dropshipping, TikTok Shop, catalog |
| `lead-gen.md` | Forms, calls, DMs, B2B, local services |
| `finance-investment.md` | Trading, crypto, loans, credit, insurance, fintech |
| `igaming-casino.md` | Casino, betting, lottery, social casino |
| `app-promotion.md` | Installs, in-app events, SKAN, Minis |

Missing a vertical (nutra, dating, education)? The shape ports from the nearest file; the gate does
not. Run `references/08-policy-verticals-geo.md` Q1/Q2 first, every time.
